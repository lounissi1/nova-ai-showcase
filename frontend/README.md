# Frontend (excerpt)

The Nova AI dashboard is a Next.js application (about 15,000 lines of TypeScript, not included
in this showcase).

**Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS · Radix UI · Recharts · React Flow ·
Framer Motion · Clerk · next-themes (light and dark).

**Main screens**

| Area | What it shows |
|---|---|
| Dashboard | Revenue, profit, margin and data-quality KPIs; 7D / 30D / 90D / all trends; forecasts with confidence bands |
| Ask AI | Plain-English questions with grounded answers, evidence, limitations and suggested charts |
| Data sources | Connect and map sources, profile CSVs, preview column mappings, sync history |
| Source intelligence | Per-source readiness, quality issues and suggested analyst questions |
| Pipelines and workflows | Agent workflow runs, stage-by-stage status and logs, visual builder (React Flow) |
| Monitoring | Run health, queues and runtime status, shown only from real telemetry |
| Settings | Workspaces, theme, safe configuration readiness checks |

Screenshots: see `docs/assets/` (added from a local run).
